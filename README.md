
# 喵島職場人生（Meow Island Office Life）v9

一款純前端、單一 HTML 檔的職場人生模擬遊戲。你是一隻剛滿 22 歲的貓，進入虛構的「喵喵金控」擔任數據分析專員，一局約 6 分鐘，從 22 歲走到 65 歲退休。

## 🎮 立即遊玩

👉 **https://polarbeeeer.github.io/meow-island/**

手機直式優化，打開網址就能玩。網址後面加上 `#種子碼`（例如 `#AB12CD`）可以和朋友挑戰同一個出身。進度每年自動存在瀏覽器裡，關掉頁面也能繼續上一局。

## 玩法

1. **投胎**：取名字、選貓咪品種、輸入或隨機產生命運種子碼。
2. **前情提要**：家庭、學歷、個性與四項天賦數值（IQ、EQ、幸運、體質）隨機產生，另有兩項隱藏數值（誠信口碑、職場手腕）結算時揭曉。
3. **職場人生**：每年一個事件、固定 3 個選項；專長練得越高，越進階的選項才會出現。另有玩家無法控制的命運事件。
4. **65 歲退休**：從 100 種退休結局中依你的一生抽出 5 個選項。約 3% 的人生會因重大事故、重大疾病提早結束，或因中樂透、龐大意外之財而自行選擇提早退休。

## 核心系統

- **必定遇到的職場雜務與懷舊梗**：每個人都會遇到 2 題職場雜務（訂下午茶、部門福委、小總務、預算窗口、教新人 SQL 等）與 2 題 70–90 後的懷舊時事梗。
- **職稱會一直變**：職稱由部門、職等與兼任角色組成，年資晉升、部門調動（AI 應用、風控數據、海外分行數據等）與兼任角色都會改變職稱，每次變動都會跳出提示。
- **8 階職位**：數據分析專員 → 資深專員 → 主任 → 襄理 → 經理 → 資深經理 → 數據策略處長 → 數據長 CDO。每年底依年資、專業、績效、主管好感、人脈、專案戰功與隱藏的誠信口碑考核，條件全到後還要看名額與運氣；裁員或過勞會降職，被挖角可直接升一級。
- **日常重心**：精進專業／經營人脈／保命要緊，可隨時切換。
- **投資**：不投資／低／中／高風險，設定每年投入比例，可加碼或贖回；每季結算的虛構市場。
- **天賦有天花板**：成長量 = 努力量 ×（天花板 − 目前值）÷（天花板 − 最低值）。
- **因果線**：路口的老喵奶奶、誠信口碑與稽核、過勞休養少領薪水，結算時一次揭曉。
