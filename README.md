# 喵島職場生活｜MEOW ISLAND

一款純前端、單一 HTML 檔的職場人生模擬遊戲。你的貓從 22 歲的數據分析專員開始，一路走到 65 歲退休結算。手機打開網頁就能玩，一局約 10 分鐘，可切換 2×、4× 快轉。

## 🎮 立即遊玩

👉 **https://polarbeeeer.github.io/meow-island/**

## 玩法

- **節奏**：參考《未完人生》，時間按季流動（1× 每年 9 秒）。一局約 30 個關鍵選擇排在固定年齡，年輕時每年一次，之後越來越疏；生活小事每年約七成機率自動發生；降職與底階警訊符合條件時在年初插入。資產每季入帳。
- **畫面**：上方只顯示年齡、職位與資產，下方是事件卡。遇到選擇題會跳出視窗，從題目出現到你看完結果按「繼續」之前，時間完全暫停。
- **題庫**：職場事件 233 題、生活事件 71 題，依年齡級距（22～25、26～29、30～34、35～39、40～44、45～47、48～65 歲）與職等抽題。
- **職等**：數據分析專員 → 資深分析師 → 組長 → 經理 → 部門主管 → 高階主管。年末四項職涯值都達到門檻才升職；保障期過後三項不達標就隔年降一級。
- **資產**：依職等年薪，每年存下三成。
- **品種**：44 種貓咪可選，含日本短尾貓、英短金漸層與銀漸層等。
