# 喵島職場人生（Meow Island Office Life）

一款純前端、單一 HTML 檔的職場人生模擬遊戲。你是一隻剛滿 22 歲的貓，進入虛構的「喵喵金控」擔任數據分析師，一局約 6 分鐘，從菜鳥一路走到 65 歲退休。

## 🎮 立即遊玩

👉 https://polarbeeeer.github.io/meow-island/

手機直式優化，打開網址就能玩，不需安裝。網址後面加上 `#種子碼`（例如 `#AB12CD`）可以和朋友挑戰同一個出身。

## 玩法

1. **投胎**：取名字、選貓咪品種、輸入或隨機產生命運種子碼。
2. **前情提要**：0–22 歲的背景由種子隨機決定，包含家庭、學歷、個性，以及四項天賦數值（IQ、EQ、幸運、體質）和它們的天花板。
3. **職場人生**：每年一個抉擇事件，時間到沒選就自動選預設項。另外還有玩家無法控制的「命運事件」。
4. **結算**：D 到 SSS 評分、幸福感與資產曲線、職涯里程碑、成就圖鑑。

## 核心規則

- **天賦數值有天花板**：每次選擇帶來的成長量 = 努力量 ×（天花板 − 目前值）÷（天花板 − 最低值）。越接近天花板，越難再往上。
- **命運事件受數值影響**：例如 IQ 越高越不容易被詐騙、損失也越小；體質越好，生病越輕；EQ 影響裁員與功勞被搶；幸運影響意外之財與股市漲跌。
- **專長門檻**：8 項專長各有潛力上限，部分選項需要專長達到指定等級才能選。用 🎲 特訓骰提升。
