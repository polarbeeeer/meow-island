# 喵島職場生活｜MEOW ISLAND

一款純前端、單一 HTML 檔的職場人生模擬遊戲。你的貓從 22 歲的數據分析專員開始，一路走到 65 歲退休結算。手機打開網頁就能玩，一局大約 6 分鐘。

## 🎮 立即遊玩

👉 **https://polarbeeeer.github.io/meow-island/**

## 玩法

- **畫面**：由上到下依序是資訊列（年齡、職位、資產）、答題區、喵島。答題區固定在畫面中間，作答時答題卡會加上外框、喵島變暗，從題目出現到按下「繼續」之前，時間完全暫停。
- **題庫**：職場事件 233 題、生活事件 71 題，依年齡級距（22～25、26～29、30～34、35～39、40～44、45～47、48～65 歲）與職等抽題。
- **職等**：數據分析專員 → 資深分析師 → 組長 → 經理 → 部門主管 → 高階主管。年末四項職涯值都達到門檻才升職；保障期過後三項不達標就隔年降一級。
- **資產**：依職等年薪，每年存下三成。
- **品種**：44 種貓咪可選，含日本短尾貓、英短金漸層與銀漸層等。
