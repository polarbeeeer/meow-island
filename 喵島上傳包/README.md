# 喵島職場生活｜MEOW ISLAND

一款純前端、單一 HTML 檔的職場人生模擬遊戲。你的貓從 22 歲的數據分析專員開始，一路走到 65 歲退休結算。手機打開網頁就能玩，一局約 6 分鐘。

## 🎮 立即遊玩

👉 **https://polarbeeeer.github.io/meow-island/**

## 玩法

- **畫面**：上方只顯示年齡、職位與資產，下方是事件卡。遇到選擇題會跳出視窗，從題目出現到你看完結果按「繼續」之前，時間完全暫停。
- **0～22 歲命盤**：出生地、家境、童年、中學、大學經歷、個性全部隨機，每一項都可能在職場上回來找你（童年霸凌過的同學成了風控長、環島認識的民宿老闆邀你接手…）。
- **題目設計（借鏡《鬼島人生》）**：一局約 27 道選擇題，前期密、後期疏；沒有選擇題的年份只跑不暫停的小事件。題目依優先順序出：劇情鏈後續 → 時代大事件 → 條件劇情題／職場日常／生活日常加權抽。
  - **條件出題**：依年齡、職等、背景旗標、數值門檻決定能不能抽到（組長才會遇到「比你資深的組員」，心理餘裕太低才會遇到身心題）。
  - **多段劇情鏈**：現在的選擇會在幾年後回來，例如季報造假 → 稽核、副業 → 投資人 → 創業、戀愛 → 結婚 → 小喵 → 會考。
  - **能力判定**：部分選項依數值與幸運擲骰，成功失敗結果不同。
  - **時代大事件**：每局隨機遇到 2～3 件（疫情、AI 浪潮、金融海嘯、併購）。
  - **隱藏結局**：外商總監、創業上市、回家接班、海邊民宿，都要靠劇情鏈一路走到。
- **題庫**：劇情題 70 題（含後續與里程碑），另保留職場日常 233 題、生活事件 71 題當作日常題。
- **職等**：數據分析專員 → 資深分析師 → 組長 → 經理 → 部門主管 → 高階主管。年末四項職涯值都達到門檻才升職；保障期過後三項不達標就隔年降一級。
- **資產**：依職等年薪，每年存下三成。
- **品種**：44 種貓咪可選，含日本短尾貓、英短金漸層與銀漸層等。
